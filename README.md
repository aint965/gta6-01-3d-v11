Palkon Auto: an original sunlit open-world crime game in the coastal city of Solmar. Drive Mara Venn through 8 story missions against Bastion Civic, outrun the police at 3 wanted stars, store cars in two garages, and switch between three procedural radio stations — all in a handwritten WebGL 2 engine with a deterministic city, day/sunset/night light, traffic, pedestrians and a living title screen.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD moves and drives, E gets in and out of a car, M starts a mission, Q interacts, X drops cargo, R switches radio, G takes a car from a garage, H toggles headlights, 1 / 2 / 3 switch midday / sunset / night.
